# Settings terminology

Issue: https://github.com/kortexa-ai/aicamera/issues/65

Use settings terminology in user-facing repair, status, and hidden transfer messages. Preserve
internal profile types, the compatible saved-file path and format, migration and repair behavior,
and the current visibility of transfer controls. Use the existing validation suite for this
wording-only change; do not alter installed settings or add tests that repeat the new strings.
